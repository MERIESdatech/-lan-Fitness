<h1>HTML</h1>

<p>HTML signifie HyperText Markup Language. Il permet de créer et organiser la structure d'une page web.</p>

<h1>Balise</h1>

<p>Une balise définit un élément HTML, par exemple h1 pour un titre, p pour un paragraphe, img pour une image et a pour un lien.</p>

<h1>Attribut</h1>

<p>Un attribut donne une information supplémentaire à une balise. Par exemple, href indique la destination d'un lien et src indique la source d'une image.</p>

<h1>Class</h1>

<p>L'attribut class permet de donner un nom à un ou plusieurs éléments afin de pouvoir les sélectionner et les styliser avec CSS.</p>

<h1>ID</h1>

<p>L'attribut id donne un identifiant unique à un élément HTML.</p>

<h1>Structure HTML</h1>

<p>Une page HTML contient généralement html, head et body. Le head contient les informations de la page et le body contient le contenu visible.</p>

<h1>Balises sémantiques</h1>

<p>Les balises comme header, nav, main, section, article et footer permettent d'organiser le contenu avec une structure claire.</p>

<h1>CSS</h1>

<p>CSS signifie Cascading Style Sheets. Il permet de styliser une page HTML avec les couleurs, tailles, espacements, positions et polices.</p>

<h1>Sélecteur</h1>

<p>Un sélecteur permet de choisir les éléments HTML auxquels on veut appliquer un style CSS.</p>

<h1>Box Model</h1>

<p>Le Box Model représente un élément avec son contenu, son padding, sa border et son margin.</p>

<h1>Margin</h1>

<p>Margin crée un espace extérieur autour d'un élément.</p>

<h1>Padding</h1>

<p>Padding crée un espace intérieur entre le contenu et la bordure d'un élément.</p>

<h1>Flexbox</h1>

<p>Flexbox permet d'organiser et d'aligner facilement les éléments dans une ligne ou une colonne.</p>

<h1>Gap</h1>

<p>Gap permet de créer un espace entre les éléments d'un conteneur Flexbox ou Grid.</p>

<h1>Grid</h1>

<p>CSS Grid permet d'organiser les éléments sous forme de lignes et de colonnes.</p>

<h1>Position</h1>

<p>La propriété position permet de contrôler la position d'un élément avec des valeurs comme relative, absolute, fixed et sticky.</p>

<h1>Responsive Design</h1>

<p>Le Responsive Design permet à un site web de s'adapter aux différentes tailles d'écran comme ordinateur, tablette et téléphone.</p>

<h1>Media Query</h1>

<p>Une Media Query permet d'appliquer différents styles CSS selon la taille de l'écran.</p>
